## Descripción del Proyecto

Este repositorio contiene la solución a dos problemas de conteo y combinatoria, desarrollados como bonificación para Matemáticas Discretas I. El objetivo central de este proyecto es conectar los conceptos teóricos de combinatoria vistos en clase con la programación, construyendo herramientas generales y robustas que no solo resuelvan casos aislados, sino que validen los parámetros de entrada y expliquen el razonamiento matemático subyacente.

Los dos problemas seleccionados y desarrollados son:
 **Problema 1:** Calculadora general de permutaciones y k-permutaciones.
 **Problema 2:** Calculadora general de combinaciones. 

## Estructura del Repositorio

- `main.py` / `notebook.ipynb` : Archivo principal con el código fuente estructurado en funciones modulares.
- `README.md` : Este archivo con la documentación del proyecto.
- `/evidencias` : Este archivo contiene evidencias de la ejecución correcta del programa.
